## About Me:
I'm a Final Year Computer Engineering student at Nanyang Technological University (NTU), Singapore, with a strong passion for Software Engineering, Data Engineering, and High-Performance Computing. I enjoy building software systems and exploring areas such as data pipelines, distributed computing, and performance optimization through personal projects, coursework, and technical competitions.

I'm currently building a visual platform for constructing and executing data pipelines, while optimizing ML training workloads for MLPerf Training.

Beyond academics, I enjoy basketball and poetry. I'm always keen to connect, collaborate, and learn from others, so feel free to explore my repositories or reach out!

## Projects:
- [Budget-Buddy](https://github.com/27July/budget-buddy): A desktop application for local expense tracking featuring interactive charts and visualisations to help users better understand and manage their finances
- [HPC/AI-Website](https://ntuhpc.org/): Built the official website for NTU's student High-Performance Computing and AI team, showcasing its competitions, achievements, research, events, and community
- [Debug-Diary](https://github.com/27July/debug-diary): A simple personal bug-tracking app for logging issues, fixes, and ownership
- [Personal-Blogging-API](https://github.com/27July/personal-blogging-api): A dockerised REST API for a simple personal blog with basic auth and article CRUD with ownership enforcement
- [Personal Website](https://github.com/27July/27july.github.io): A simple personal website, deployed on GitHub Pages, to showcase my projects
- [ChildConnect](https://github.com/27July/ChildConnect): A cross-platform mobile application for educators designed to streamline communication between educators and parents, featuring child tracking, real-time messaging with translation and speech integration, homework or document sharing and attendance management
- [Stickmanify](https://github.com/HackOSS-Stickmanify): An AI-powered web application that transforms uploaded videos into stylized stickman animations using a custom LoRA-based image-generation pipeline. (Contributed as part of Web Development team)
- [Navigoat](https://github.com/27July/navigoat): Built a Chrome extension that uses LLM-powered page parsing to declutter websites, relabel ambiguous UI elements, and present links/actions in an accessible layout with Dyslexia/ADHD modes. Submited as part of my hackathon entry for iNTUition V12.0
- [Verify-AI-Chrome-Extension](https://github.com/27July/Verify-AI-Chrome-Extension): A chrome extension that empowers users to verify textual misinformation and deepfake images using machine learning modals directly within their browser. Submitted as part of my hackathon entry for NTU Techfest 2025
- [Multidisciplinary-Design-Project](https://github.com/27July/SC2079-Multidisciplinary-Design-Project): An autonomous robot system with navigation and visual recognition, utilising an STM32 RTOS-based motor/steering control for reliable movement execution (Contributed as part of the STM team)
- [Essay-Quality-Prediction](https://github.com/27July/SC4000-Essay-Quality-Prediction): A machine learning project based on the “Linking Writing Processes to Writing Quality” Kaggle competition that predicts essay scores from keystroke dynamics and text features using DeBERTa embeddings, topic modelling and ensemble models
- [Hospital-Management-System](https://github.com/27July/SC2002-Hospital-Management-System): A command-line hospital management system built upon core Object-Oriented Programming principles
- [Heart-Disease-Prediction](https://github.com/27July/SC1015-Heart-Disease-Prediction): A machine learning project utilising decision trees, random forest and logistical regression to predict whether a patient has heart disease
